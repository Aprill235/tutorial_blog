Features and Targets in Machine Learning

When training a model, we need to answer two important questions:

  1. What information should the model use to make predictions?
  2. What are we trying to predict?

These questions introduce two fundamental concepts in supervised machine learning: features and targets.

In this tutorial, we’ll learn how to identify features and targets, separate them using Python’s pandas library, and avoid common mistakes when choosing variables for a prediction problem.

1. What Are Features and Targets?

In machine learning, a model learns patterns from data containing input variables and known outcomes.

Features: input variables a model uses to make predictions. They provide information that may help explain or predict an outcome.

Target: variable we want the model to predict. It is also sometimes called the response variable or dependent variable.

Let’s consider our house-price example.

If we want to predict a house’s selling price, we might use the following variables:

yaVariable Description Role
YearRemodAdd Remodel date (same as construction date if no remodeling or additions) Feature
Neighborhood Physical locations within Ames city limits Feature
GrLivArea Above grade (ground) living area square feet Feature
SalePrice Selling price Target

The features provide information about each house, while the target represents the outcome we want to predict.

We can describe this relationship as:

Features (\(X\)) → Machine-Learning Model → Predicted Target (\(\hat{y}\))

In machine learning, features are commonly represented by X, while the target is represented by y.

An important distinction is that a variable is not automatically a feature or target based on its name or data type. Its role depends on the prediction question.

3. Separating Features and Targets with pandas

Once we’ve identified our features and target, we can separate them into different variables using pandas.

In machine learning, we commonly use X to represent the features and y to represent the target.

X = houses[["YearRemodAdd", "Neighborhood", "GrLivArea"]]
y = houses["SalePrice"]

Let’s break down this code.

X contains our features.

We use double square brackets because we’re selecting multiple columns from the DataFrame. The result is another DataFrame containing only our three selected features.

An Alternative: Using .drop()

Another way to separate features and the target is by using pandas’ .drop() method.

X = houses.drop(columns=["Id", "SalePrice"])
y = houses["SalePrice"]

However, there is an important difference between this approach and our earlier code.

The earlier code explicitly selected three features, while .drop() removed only Id and SalePrice, leaving all the other columns as features.

Since our dataset contains many variables, these two approaches produce different feature sets.

For this tutorial, we’ll continue using only our three selected features:

X = houses[["YearRemodAdd", "Neighborhood", "GrLivArea"]]
y = houses["SalePrice"]

You can learn more about selecting and removing columns in the official pandas DataFrame.drop() documentation.

Why Do We Separate X and y?

Many supervised machine-learning tools expect the features and target to be provided separately.

For example, a typical model in scikit-learn is trained using the following structure:

model.fit(X, y)

Here, X contains the information used to learn patterns, while y provides the known outcomes.

Note: This is a conceptual example, not code to run yet. We haven’t created a model, and our categorical feature Neighborhood would need to be encoded for many machine-learning algorithms.

The main takeaway is that separating X and y is an essential preparation step before training a supervised machine-learning model.

4. Choosing the Right Features

Identifying the target is usually straightforward once we know our prediction question. However, choosing appropriate features requires more consideration.

Let’s look at three important questions to ask when selecting features.

1. Does the Variable Contain Potentially Useful Information?

For our housing dataset, GrLivArea could be a useful feature because larger houses may tend to have higher selling prices.

Similarly, Neighborhood could provide useful information because house prices often vary depending on location.

However, Id is simply an identifier assigned to each observation. It does not necessarily contain meaningful information about a house’s value.

When choosing features, we should consider whether each variable could help explain or predict the target.

2. Will This Information Be Available When Making Predictions?

Suppose we want to predict a house’s selling price before it is sold.

We can reasonably use information such as its living area, neighborhood, and remodeling year because these characteristics can be known before the sale.

However, we cannot use the final selling price itself as a feature because that information would not yet be available.

Using information that would not be available at prediction time can cause data leakage.

Data leakage occurs when information that should not be available to a model is used during training or evaluation. This can make the model appear more accurate than it would be when making predictions on new data.

3. Are We Accidentally Including the Target?

One common mistake is including the target variable among the features.

For example:

# Incorrect: SalePrice is included in X
X = houses.drop(columns=["Id"])
y = houses["SalePrice"]

Here, SalePrice appears in both X and y.

This means the model would have access to the very value it is supposed to predict!

Instead, we should exclude the target from our features.

# Correct
X = houses[["YearRemodAdd", "Neighborhood", "GrLivArea"]]
y = houses["SalePrice"]

For more information about data leakage, check out scikit-learn’s guide to common pitfalls.

Conclusion

Understanding the difference between features and targets is an essential first step in building a supervised machine-learning model.

Remember:

  • Features (X) are the input variables used to make predictions.
  • The target (y) is the outcome we want the model to predict.
  • A variable’s role depends on the prediction question.
  • Features can be numerical or categorical.
  • Not every available variable should automatically be included as a feature.
